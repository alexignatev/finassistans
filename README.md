# Минималистичный сайт компании

Минималистичный сайт с черно-белой палитрой и темно-синим акцентом, созданный на HTML, CSS и JavaScript с использованием GSAP для анимаций.

## Структура сайта

### Основные страницы:
- `index.html` - Главная страница
- `situations.html` - Ситуации (карточки подстраниц)
- `work.html` - Как мы работаем (4-шаговый цикл)
- `tools.html` - Наши инструменты (карточки подстраниц)
- `tech.html` - Технологический контур
- `team.html` - Команда
- `industries.html` - Отрасли (карточки подстраниц)
- `contacts.html` - Контакты

### Подстраницы:
- `situations/` - Подстраницы ситуаций
  - `emergency.html` - Экстренная стабилизация
- `tools/` - Подстраницы инструментов
  - `diagnostics.html` - Диагностика и наведение порядка в данных
- `industries/` - Подстраницы отраслей
  - `production.html` - Производство

### Компоненты:
- `components/header.html` - Навигация (загружается динамически)
- `components/footer.html` - Футер (загружается динамически)
- `components/loader.js` - Скрипт загрузки компонентов

## Особенности

- Минималистичный дизайн в стиле chadsn
- Черно-белая палитра с темно-синим акцентом (#1a365d)
- GSAP анимации для плавных переходов
- Адаптивный дизайн для мобильных устройств
- Фиксированная навигация с эффектом размытия
- Карточки с hover-эффектами
- Форма обратной связи на странице контактов
- Модульная архитектура с переиспользуемыми компонентами

## Технологии

- HTML5
- CSS3 (Grid, Flexbox, анимации)
- JavaScript (ES6+)
- GSAP (GreenSock Animation Platform)

## Запуск

Откройте `index.html` в браузере для просмотра сайта.

## Архитектура

Сайт использует модульную архитектуру с компонентами:
- Header и footer вынесены в отдельные файлы
- Автоматическая загрузка компонентов через JavaScript
- Автоматическая корректировка путей для подстраниц
